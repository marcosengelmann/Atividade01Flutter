## Descrição da atividade

Esta atividade consiste no desenvolvimento de uma aplicação Flutter, aplicando conceitos de widgets, organização de interfaces, interação com o usuário, execução da aplicação, controle de versão com Git e publicação no GitHub.

## Descrição da aplicação

A aplicação **Minhas Tarefas** permite que o usuário cadastre tarefas por meio de um campo de texto e de um botão. As tarefas adicionadas são exibidas dinamicamente na tela e podem ser removidas.

## Principais funcionalidades

* Interface desenvolvida utilizando Flutter;
* AppBar com título;
* Campo para inserção de tarefas;
* Botão para adicionar tarefas;
* Exibição dinâmica das tarefas;
* Remoção de tarefas;
* Atualização da interface utilizando `setState()`.

## Tecnologias utilizadas

* Flutter
* Dart
* Git
* GitHub

## Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd atividade_flutter
```

Instale as dependências:

```bash
flutter pub get
```

Conecte um dispositivo Android ou inicie um emulador.

Execute o projeto:

```bash
flutter run
```
